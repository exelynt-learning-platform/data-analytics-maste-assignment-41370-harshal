## 5. Local vs Remote Repository

Local Repository:
A local repository is stored on our computer. We use it to create files, track changes, and commit changes.

Remote Repository:
A remote repository is stored online on platforms like GitHub. It allows developers to share code and collaborate.

Difference:
A local repository is stored on our computer, whereas a remote repository is stored on an online server.
