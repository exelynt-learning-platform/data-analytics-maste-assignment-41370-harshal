## 5. Difference Between Local and Remote Repository

Local Repository:
A local repository is stored on our computer. We use it to create files, track changes, and commit our work.

Remote Repository:
A remote repository is stored online on platforms such as GitHub. It allows developers to upload, share, and collaborate on projects.

Main Difference:
A local repository is stored on our computer, whereas a remote repository is stored on an online server.
