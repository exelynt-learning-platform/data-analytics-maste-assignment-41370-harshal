## What Version Control Is and Why It Is Important
Version control is a system that tracks and saves every change we make to our project files over time. Instead of manually saving multiple copies of the same file, it keeps a clean history of all updates. It is important because if I make a mistake or my code breaks, I can easily go back to an older working version. It also helps when working in a team so everyone can see what changes were made and when.

## Why Developers Use Git
Developers use Git because it is fast, reliable, and works directly on our local computer without needing an internet connection all the time. One of the best features of Git is branching, which lets me try out new ideas or fix issues separately without affecting the main working project. Since almost every company and team uses Git, learning it is essential for working on real-world projects.

## Common Problems Git Solves
Losing work -- If a file gets deleted or broken by mistake, Git lets me recover previous saved versions easily.
Confusing file names -- We don't have to create messy copies like project_v1, project_final, or project_final2 anymore.

## Difference Between Git and GitHub
Git and GitHub work together, but they are different things:
Git is the actual software tool installed on my local computer that tracks file changes, manages branches, and saves project history.
GitHub is an online website where we upload and store our Git repositories. It acts as a cloud backup and makes it easy to share projects and collaborate with other people.

## Centralized vs. Distributed Version Control Systems
-- Centralized Version Control (CVCS): In a centralized system, the entire project history is stored on only one main server. Developers have to connect to that server over the internet to save their changes or check old versions. 
-- Distributed Version Control (DVCS): Git is a distributed system. Instead of relying on just one server, every developer gets a complete copy of the whole repository and its full history on their own computer.
